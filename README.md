# 🐍 Portafolio de Proyectos y Ejercicios en Python

Repositorio dedicado al desarrollo de lógica, estructuras de datos, automatización y arquitectura de software en Python

## 📂 Estructura del Repositorio

### 🟢 [Nivel Básico](./basico)
Scripts enfocados en el dominio de la sintaxis, manejo de excepciones, persistencia en archivos planos, estructuras de datos y consumo básico de APIs.
* **`respuestas_aleatorias.py`**: Simulador tipo *Magic 8-Ball* con probabilidades ponderadas (`random.choices`) e historial persistente con marcas de tiempo.
* **`conversor.py`**: Conversor de unidades y divisas utilizando despacho por diccionarios (*dictionary dispatch*), funciones `lambda` y consumo de API en tiempo real.
* **`quiz.py`**: Juego interactivo de preguntas y respuestas por terminal con control de flujo y puntuación.

### 🟡 [Nivel Intermedio](./intermedio)
Proyectos multi-archivo aplicando separación de responsabilidades, bases de datos relacionales, creación de APIs y visualización de datos.
* **[Temporizador Pomodoro & Dashboard](./intermedio/Pomodoro)**: Sistema completo de gestión de tiempo con interfaz de consola (`Rich`), notificaciones nativas del SO (`Plyer`), persistencia en `SQLite`, backend en `FastAPI` y panel analítico en `Streamlit`.
